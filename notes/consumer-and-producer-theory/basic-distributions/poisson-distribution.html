Mass Function and Properties

If a discrete random variable XXX is drawn from a Poisson distribution with with a parameter λ>0\lambda>0λ>0, then:

X∼Poisson(λ)(2.1.5.1)X\sim \text{Poisson}(\lambda) \tag{2.1.5.1}X∼Poisson(λ)(2.1.5.1)

The pmf is:

P(X=k)=λke−λk!,k=0,1,2,...(2.1.5.2)P(X=k)=\frac{\lambda^ke^{-\lambda}}{k!},\quad k=0,1,2,... \tag{2.1.5.2}P(X=k)=k!λke−λ​,k=0,1,2,...(2.1.5.2)

E[X]=λ(2.1.5.3)\mathbb{E}[X]=\lambda \tag{2.1.5.3}E[X]=λ(2.1.5.3)

The variance is:

Var(X)=λ(2.1.5.4)\text{Var}(X)=\lambda \tag{2.1.5.4}Var(X)=λ(2.1.5.4)

How to Understand?

In Poisson Distribution, there is a time period TTT, and the probability that an event happens during this time period is λ\lambdaλ (Poisson Parameter). Now let's divide the time period TTT into nnn different small intervals Tt\frac{T}{t}tT​, and suppose that the event has an equal probability to happen in these small time intervals λn\frac{\lambda}{n}nλ​. For each time interval, the probability that the event does happen is:

p=1−λn(2.1.5.5)p=1-\frac{\lambda}{n} \tag{2.1.5.5}p=1−nλ​(2.1.5.5)

Then the probability that no event happens during the whole period is:

P(N=0)=pn=(1−λn)n(2.1.5.6)P(N=0)=p^{n}=\left(1-\frac{\lambda}{n}\right)^n \tag{2.1.5.6}P(N=0)=pn=(1−nλ​)n(2.1.5.6)

Now let's have an infinite number of small time intervals, or n→∞n\rightarrow \inftyn→∞, we have:

P(N=0)=lim⁡n→∞(1−λn)n=e−λ(2.1.5.7)P(N=0)=\mathop{\lim}_{n\rightarrow \infty}\left(1-\frac{\lambda}{n}\right)^n=e^{-\lambda} \tag{2.1.5.7}P(N=0)=limn→∞​(1−nλ​)n=e−λ(2.1.5.7)
