Properties of CES Utility Function

If the consumer has a utility function in the form of CES like:

U=(∑i=1kxiσ−1σ)σσ−1,  σ∈(1,∞)(2.2.1.14)U=(\sum_{i=1}^kx_i^{\frac{\sigma-1}{\sigma}})^{\frac{\sigma}{\sigma-1}},\; \sigma\in (1,\infty) \tag{2.2.1.14}U=(i=1∑k​xiσσ−1​​)σ−1σ​,σ∈(1,∞)(2.2.1.14)

then we have several conclustions as below:

(1) We can define a Dixit-Stiglitz price index, which can measure the aggregate price index faced by the consumer:

P=(∑i=1kpi1−σ)11−σ(2.2.1.15)P=(\sum_{i=1}^kp_i^{1-\sigma})^{\frac{1}{1-\sigma}} \tag{2.2.1.15}P=(i=1∑k​pi1−σ​)1−σ1​(2.2.1.15)

(2) With the Dixit-Stiglitz price index, we have:

U=wP=(∑i=1kxiσ−1σ)σσ−1(2.2.1.16)U=\frac{w}{P}=(\sum_{i=1}^kx_i^{\frac{\sigma-1}{\sigma}})^{\frac{\sigma}{\sigma-1}} \tag{2.2.1.16}U=Pw​=(i=1∑k​xiσσ−1​​)σ−1σ​(2.2.1.16)

(3) The (Marshallian) demand for each variety of good is:

in which σ\sigmaσ can be regarded as the price elasticity of demand. This is a very strong assumption.
