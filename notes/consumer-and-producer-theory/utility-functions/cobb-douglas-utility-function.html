Basic Model

Cobb-Douglas function is a special case of CES when σ=1\sigma=1σ=1. Let's define a Cobb-Douglas utility function1:

U=ΠnNxnαn(2.2.2.1)U=\Pi_n^Nx_n^{\alpha_n} \tag{2.2.2.1}U=ΠnN​xnαn​​(2.2.2.1)

subject to the budget constraint:

w=∑i=1npixi(2.2.2.2)w=\sum_{i=1}^np_ix_i \tag{2.2.2.2}w=i=1∑n​pi​xi​(2.2.2.2)

where

∑i=1nαi=1(2.2.2.3)\sum_{i=1}^{n}\alpha_i=1 \tag{2.2.2.3}i=1∑n​αi​=1(2.2.2.3)

The Lagrangian is:

L=ΠnNxnαn−λ(∑i=1npixi−w)(2.2.2.4)\mathcal{L}=\Pi_n^Nx_n^{\alpha_n}-\lambda(\sum_{i=1}^np_ix_i-w) \tag{2.2.2.4}L=ΠnN​xnαn​​−λ(i=1∑n​pi​xi​−w)(2.2.2.4)

The F.O.C. on xix_ixi​ is:

∂L∂xi=αixiαi−1Πn≠iNxnαn−λpi=αiUxi−λpi=0(2.2.2.5)\frac{\partial \mathcal{L}}{\partial x_i}=\alpha_ix_i^{\alpha_i-1}\Pi_{n\neq i}^Nx_n^{\alpha_n}-\lambda p_i=\alpha_i\frac{U}{x_i}-\lambda p_i=0 \tag{2.2.2.5}∂xi​∂L​=αi​xiαi​−1​Πn=iN​xnαn​​−λpi​=αi​xi​U​−λpi​=0(2.2.2.5)

We can find:

xi=αiUλpi(2.2.2.6)x_i=\frac{\alpha_i U}{\lambda p_i} \tag{2.2.2.6}xi​=λpi​αi​U​(2.2.2.6)

Similarly, we have:

xj=αjUλpj(2.2.2.7)x_j=\frac{\alpha_j U}{\lambda p_j} \tag{2.2.2.7}xj​=λpj​αj​U​(2.2.2.7)

Then we have:

xixj=αiαjpjpi  ⇒  xi=(αiαjpjpi)xj(2.2.2.8)\frac{x_i}{x_j}=\frac{\alpha_i}{\alpha_j}\frac{p_j}{p_i}\;\Rightarrow\; x_i=\left(\frac{\alpha_i}{\alpha_j}\frac{p_j}{p_i}\right)x_j \tag{2.2.2.8}xj​xi​​=αj​αi​​pi​pj​​⇒xi​=(αj​αi​​pi​pj​​)xj​(2.2.2.8)

Recall the budget constraint:

w=∑i=1npixi(2.2.2.9)w=\sum_{i=1}^np_ix_i \tag{2.2.2.9}w=i=1∑n​pi​xi​(2.2.2.9)

Then we can write it as:

w=∑i=1npixi=∑i=1npi(αiαjpjpi)xj=∑i=1n(αiαj)pjxj=pjxjαj∑i=1nαi=pjxjαj(2.2.2.10)w=\sum_{i=1}^np_ix_i=\sum_{i=1}^np_i\left(\frac{\alpha_i}{\alpha_j}\frac{p_j}{p_i}\right)x_j=\sum_{i=1}^n\left(\frac{\alpha_i}{\alpha_j}\right)p_jx_j=\frac{p_jx_j}{\alpha_j}\sum_{i=1}^n\alpha_i=\frac{p_jx_j}{\alpha_j} \tag{2.2.2.10}w=i=1∑n​pi​xi​=i=1∑n​pi​(αj​αi​​pi​pj​​)xj​=i=1∑n​(αj​αi​​)pj​xj​=αj​pj​xj​​i=1∑n​αi​=αj​pj​xj​​(2.2.2.10)

Therefore, we have the Marshallian demand for good jjj:

xj=αjwpj(2.2.2.11)x_j=\frac{\alpha_j w}{p_j} \tag{2.2.2.11}xj​=pj​αj​w​(2.2.2.11)

The indirect utility function is:

U=x1α1x2α2...αnαn=Πi=1n(αiwpi)αi=w⋅Πi=1n(αipi)αi(2.2.2.12)U=x_1^{\alpha_1}x_2^{\alpha_2}...\alpha_n^{\alpha_n}=\Pi_{i=1}^{n}\left(\frac{\alpha_iw}{p_i}\right)^{\alpha_i}=w\cdot\Pi_{i=1}^{n}\left(\frac{\alpha_i}{p_i}\right)^{\alpha_i} \tag{2.2.2.12}U=x1α1​​x2α2​​...αnαn​​=Πi=1n​(pi​αi​w​)αi​=w⋅Πi=1n​(pi​αi​​)αi​(2.2.2.12)

Properties of Cobb-Douglas Utility Function

If the consumer has a utility function in the form of Cobb-Douglas like:

U=Πixiαi(2.2.2.13)U=\Pi_ix_i^{\alpha_i} \tag{2.2.2.13}U=Πi​xiαi​​(2.2.2.13)

then we have several conclustions as below:

(1) The Marshallian demand is:

xi=αiwpi(2.2.2.14)x_i=\frac{\alpha_i w}{p_i} \tag{2.2.2.14}xi​=pi​αi​w​(2.2.2.14)

(2) We can also express the demand curve as:

ln(xi)=ln(w)+ln(αi)−ln(pi)(2.2.2.15)\text{ln}(x_i)=\text{ln}(w)+\text{ln}(\alpha_i)-\text{ln}(p_i) \tag{2.2.2.15}ln(xi​)=ln(w)+ln(αi​)−ln(pi​)(2.2.2.15)

where the price elasticity of demand is 1.

(3) The indirect utility can be expressed as:

U=w⋅Πi(αipi)αi(2.2.2.16)U=w\cdot\Pi_{i}\left(\frac{\alpha_i}{p_i}\right)^{\alpha_i} \tag{2.2.2.16}U=w⋅Πi​(pi​αi​​)αi​(2.2.2.16)
