Cobb-Douglas production function is also a very popular production function in the economic analysis. Compared with CES production function, Cobb-Douglas production function is often used in the production of the aggregate economy, rather than a single firm. Some previous studies like Houthakker (1955) and Jones (2005) have shown that if the technology is drawn from a Pareto distribution, then all types of micro-level production functions will be aggregated to a Cobb-Douglas total production function. The details can be found in the Section Aggregation. Therefore, in macroeconomics, we only use Cobb-Douglas production function to analyze the aggregated economy.
