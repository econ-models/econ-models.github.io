The nested logit model is a type of GEV models, and it relaxes the substitution pattern limitation in the logit models. In a nested logit model, the set of alternatives can be partitioned into different subsets (nests). Let the set of alternatives jjj be partitioned into KKK nonoverlapping subsets denoted B1,B2,...,BKB_1, B_2,..., B_KB1​,B2​,...,BK​.
