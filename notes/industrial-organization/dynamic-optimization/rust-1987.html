Model Setting

The model follows Rust (1987). A bus manager decides in each period whether to keep the current engine or replace it. The state variable is the accumulated mileage since the last engine replacement, denoted by xtx_txt​. Mileage is discretized into a finite state space:

xt∈{0,1,…,xˉ}.(7.3.1.1)x_t \in \{0,1,\ldots,\bar{x}\}. \tag{7.3.1.1}xt​∈{0,1,…,xˉ}.(7.3.1.1)

In the empirical implementation, one state corresponds to a 5,000-mile interval.

The manager chooses an action at∈{0,1}a_t\in\{0,1\}at​∈{0,1}, where at=0a_t=0at​=0 denotes keeping the current engine and at=1a_t=1at​=1 denotes replacing the engine. The per-period utility is:

u(xt,at,ϵt)={−c(xt;θc)+ϵ0t,at=0,−RC−c(0;θc)+ϵ1t,at=1,(7.3.1.2)u(x_t,a_t,\epsilon_t)= \begin{cases} -c(x_t;\theta_c)+\epsilon_{0t}, & a_t=0,\\ -RC-c(0;\theta_c)+\epsilon_{1t}, & a_t=1, \end{cases} \tag{7.3.1.2}u(xt​,at​,ϵt​)={−c(xt​;θc​)+ϵ0t​,−RC−c(0;θc​)+ϵ1t​,​at​=0,at​=1,​(7.3.1.2)

where c(xt;θc)c(x_t;\theta_c)c(xt​;θc​) is the maintenance cost, which increases with mileage, RCRCRC is the engine replacement cost, and ϵat\epsilon_{at}ϵat​ is an action-specific utility shock observed by the manager but not by the econometrician. A simple specification for the maintenance cost is:

c(xt;θc)=θcxt.(7.3.1.3)c(x_t;\theta_c)=\theta_c x_t. \tag{7.3.1.3}c(xt​;θc​)=θc​xt​.(7.3.1.3)

The main trade-off is therefore between paying the one-time replacement cost today and continuing to operate an old engine with increasingly high maintenance costs.

State Transition

If the manager keeps the current engine, mileage evolves according to:

xt+1=xt+Δt,(7.3.1.4)x_{t+1}=x_t+\Delta_t, \tag{7.3.1.4}xt+1​=xt​+Δt​,(7.3.1.4)

where Δt\Delta_tΔt​ is a stochastic mileage increment. Let:

Pr⁡(Δt=j)=pj,j=0,1,2.(7.3.1.5)\Pr(\Delta_t=j)=p_j,\qquad j=0,1,2. \tag{7.3.1.5}Pr(Δt​=j)=pj​,j=0,1,2.(7.3.1.5)

These transition probabilities can be estimated directly from the observed mileage data.

If the engine is replaced, the mileage state is reset. Under the timing convention in which replacement resets the state before the next period,

xt+1=0(7.3.1.6)x_{t+1}=0 \tag{7.3.1.6}xt+1​=0(7.3.1.6)

up to the subsequent mileage realization. Therefore, the transition probability can be summarized by:

F(xt+1∣xt,at).(7.3.1.7)F(x_{t+1}|x_t,a_t). \tag{7.3.1.7}F(xt+1​∣xt​,at​).(7.3.1.7)

Dynamic Decision Problem

The manager is forward-looking and maximizes the expected discounted value of utility:

E[∑t=0∞βtu(xt,at,ϵt)],(7.3.1.8)E\left[ \sum_{t=0}^{\infty} \beta^t u(x_t,a_t,\epsilon_t) \right], \tag{7.3.1.8}E[t=0∑∞​βtu(xt​,at​,ϵt​)],(7.3.1.8)

where β∈(0,1)\beta\in(0,1)β∈(0,1) is the discount factor.

Define the choice-specific value functions excluding the contemporaneous utility shocks. The value of keeping the engine is:

v0(x)=−c(x;θc)+β∑x′F(x′∣x,0)V(x′),(7.3.1.9)v_0(x) = -c(x;\theta_c) + \beta \sum_{x'} F(x'|x,0)V(x'), \tag{7.3.1.9}v0​(x)=−c(x;θc​)+βx′∑​F(x′∣x,0)V(x′),(7.3.1.9)

while the value of replacing the engine is:

v1(x)=−RC−c(0;θc)+β∑x′F(x′∣x,1)V(x′).(7.3.1.10)v_1(x) = -RC-c(0;\theta_c) + \beta \sum_{x'} F(x'|x,1)V(x'). \tag{7.3.1.10}v1​(x)=−RC−c(0;θc​)+βx′∑​F(x′∣x,1)V(x′).(7.3.1.10)

The manager chooses replacement if:

v1(xt)+ϵ1t≥v0(xt)+ϵ0t.(7.3.1.11)v_1(x_t)+\epsilon_{1t} \geq v_0(x_t)+\epsilon_{0t}. \tag{7.3.1.11}v1​(xt​)+ϵ1t​≥v0​(xt​)+ϵ0t​.(7.3.1.11)

Rust assumes that ϵ0t\epsilon_{0t}ϵ0t​ and ϵ1t\epsilon_{1t}ϵ1t​ are i.i.d. Type-I Extreme Value. This assumption implies that the expected value function has the closed-form expression:

V(x)=log⁡[exp⁡(v0(x))+exp⁡(v1(x))],(7.3.1.12)V(x) = \log \left[ \exp(v_0(x)) + \exp(v_1(x)) \right], \tag{7.3.1.12}V(x)=log[exp(v0​(x))+exp(v1​(x))],(7.3.1.12)

up to an additive constant.

The value function is therefore the fixed point of the Bellman operator:

V=Γ(V;θ),(7.3.1.13)V=\Gamma(V;\theta), \tag{7.3.1.13}V=Γ(V;θ),(7.3.1.13)

where the structural parameter vector is:

θ=(θc,RC).(7.3.1.14)\theta=(\theta_c,RC). \tag{7.3.1.14}θ=(θc​,RC).(7.3.1.14)

Conditional Choice Probabilities

The Extreme Value assumption also generates the familiar logit choice probabilities. Conditional on mileage xxx, the probability of engine replacement is:

P(1∣x;θ)=exp⁡(v1(x))exp⁡(v0(x))+exp⁡(v1(x)),(7.3.1.15)P(1|x;\theta) = \frac{\exp(v_1(x))} {\exp(v_0(x))+\exp(v_1(x))}, \tag{7.3.1.15}P(1∣x;θ)=exp(v0​(x))+exp(v1​(x))exp(v1​(x))​,(7.3.1.15)

and the probability of keeping the current engine is:

P(0∣x;θ)=exp⁡(v0(x))exp⁡(v0(x))+exp⁡(v1(x)).(7.3.1.16)P(0|x;\theta) = \frac{\exp(v_0(x))} {\exp(v_0(x))+\exp(v_1(x))}. \tag{7.3.1.16}P(0∣x;θ)=exp(v0​(x))+exp(v1​(x))exp(v0​(x))​.(7.3.1.16)

As mileage increases, the maintenance cost of keeping the existing engine rises, which generally increases the probability of replacement.

Estimation

The mileage transition probabilities are first estimated from observed mileage changes. Conditional on these transition probabilities and a fixed discount factor β\betaβ, the structural parameters θc\theta_cθc​ and RCRCRC are estimated by maximum likelihood.

For a candidate parameter vector θ\thetaθ, the Bellman equation is first solved for its fixed point:

V∗(θ)=Γ(V∗(θ);θ).(7.3.1.17)V^{*}(\theta) = \Gamma(V^{*}(\theta);\theta). \tag{7.3.1.17}V∗(θ)=Γ(V∗(θ);θ).(7.3.1.17)

Given the resulting value function, the model generates the conditional choice probabilities P(at∣xt;θ)P(a_t|x_t;\theta)P(at​∣xt​;θ). The log-likelihood function is:

L(θ)=∑i,t[aitlog⁡P(1∣xit;θ)+(1−ait)log⁡P(0∣xit;θ)].(7.3.1.18)\mathcal{L}(\theta) = \sum_{i,t} \left[ a_{it}\log P(1|x_{it};\theta) + (1-a_{it})\log P(0|x_{it};\theta) \right]. \tag{7.3.1.18}L(θ)=i,t∑​[ait​logP(1∣xit​;θ)+(1−ait​)logP(0∣xit​;θ)].(7.3.1.18)

The structural parameter estimates are:

θ^=arg⁡max⁡θL(θ).(7.3.1.19)\hat{\theta} = \arg\max_{\theta} \mathcal{L}(\theta). \tag{7.3.1.19}θ^=argθmax​L(θ).(7.3.1.19)

Because the Bellman fixed point must be solved for every candidate parameter vector considered by the outer likelihood maximization routine, Rust refers to the procedure as the Nested Fixed Point (NFXP) algorithm:

θ→V∗(θ)→P(a∣x;θ)→L(θ).(7.3.1.20)\boxed{ \theta \rightarrow V^{*}(\theta) \rightarrow P(a|x;\theta) \rightarrow \mathcal{L}(\theta) }. \tag{7.3.1.20}θ→V∗(θ)→P(a∣x;θ)→L(θ)​.(7.3.1.20)
